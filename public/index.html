Store API tester

Click links below to see returned JSON data:

  • /api/v1/products?limit=100 - Get all products (default number of results returned is 10)
  • /api/v1/products?name=bed - Get products which contain "bed" in name
  • /api/v1/products?sort=name - Sort all products by name (a to z)
  • /api/v1/products?sort=-price - Sort all products by price (highest to lowest)
  • /api/v1/products?fields=name,company - Include only fields "name" and "company"
  • /api/v1/products?page=2&limit=5&sort=price - Get 2nd page with 5 items per page sorted by price ascending
  • /api/v1/products?numberFilters=price<100,rating>=4 - Get products which costs under 100$ and with rating equal or higher than 4
